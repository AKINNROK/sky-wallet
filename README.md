# ☁️ Sky Wallet — วิธีทำให้เป็นแอปจริงบนหน้าจอมือถือ

โฟลเดอร์นี้คือ **Progressive Web App (PWA)** เต็มรูปแบบ อัปโหลดขึ้นเว็บฟรี ๆ แล้ว
กด "ติดตั้ง" ลงหน้าจอได้เหมือนแอปจาก Play Store / App Store ทุกอย่าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ไฟล์เดียวจบ) |
| `sw.js` | Service Worker — ทำให้ **เปิดใช้ได้แม้ไม่มีเน็ต** และทำให้ปุ่ม "ติดตั้งแอป" โผล่ |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สี เปิดแบบเต็มจอ |
| `icon-*.png` / `apple-touch-icon.png` | ไอคอนน้องเมฆทุกขนาด |

---

## วิธีที่ 1 — Netlify Drop (ง่ายสุด ไม่ต้องเขียนโค้ด ~2 นาที)

1. เข้า **https://app.netlify.com/drop**
2. **ลากทั้งโฟลเดอร์นี้** (หรือไฟล์ zip) ไปวางในหน้าเว็บ
3. รอสักครู่ จะได้ลิงก์แบบ `https://ชื่อสุ่ม.netlify.app`
4. เปิดลิงก์นั้นในมือถือ → ติดตั้งได้เลย (ดูขั้นตอนด้านล่าง)
5. สมัครบัญชีฟรีเพื่อเก็บลิงก์ไว้ถาวร และเปลี่ยนชื่อเว็บได้

## วิธีที่ 2 — GitHub Pages (ฟรีถาวร)

1. สร้าง repository ใหม่ใน GitHub เช่น `sky-wallet` (ตั้งเป็น Public)
2. กด **Add file → Upload files** แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ไปที่ **Settings → Pages** → Source เลือก `main` / `root` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/sky-wallet/`

## วิธีที่ 3 — Cloudflare Pages / Vercel

อัปโหลดโฟลเดอร์เป็นโปรเจกต์ static ธรรมดา ไม่ต้องตั้งค่า build อะไรเลย

## ติดตั้งลงหน้าจอ

**Android (Chrome)** — เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** (หรือรอแบนเนอร์เด้งขึ้นมา)

**iPhone / iPad (ต้องใช้ Safari เท่านั้น)** — เปิดลิงก์ → ปุ่มแชร์ ↑ → **เพิ่มไปยังโฮมสกรีน** → เพิ่ม

**คอม (Chrome / Edge)** — เปิดลิงก์ → กดไอคอน ⊕ ท้ายช่องที่อยู่เว็บ → ติดตั้ง

ติดตั้งแล้วจะได้ไอคอนน้องเมฆบนหน้าจอ เปิดแบบเต็มจอ ไม่มีแถบเบราว์เซอร์ และ **ใช้งานได้แม้ปิดเน็ต**

---

## เรื่องข้อมูลของคุณ

* ข้อมูลทั้งหมดเก็บอยู่ใน **เครื่องของคุณเอง** (localStorage ของเบราว์เซอร์) ไม่มีการส่งขึ้นเซิร์ฟเวอร์ใด ๆ
* แต่ละอุปกรณ์จึงมีข้อมูลแยกกัน — ย้ายข้อมูลได้โดย **เมนู → 💾 สำรองข้อมูล** ที่เครื่องเดิม แล้ว **🧰 เครื่องมือ → นำเข้าไฟล์** ที่เครื่องใหม่
* เช็กสถานะได้ทุกเมื่อจากปุ่ม **☁️ / 💾** บนหัวแอป
* ⚠️ อย่ากด "ล้างข้อมูลเว็บไซต์" ในเบราว์เซอร์ และควรสำรองไฟล์ไว้เป็นระยะ

## อัปเดตแอป

อัปโหลดไฟล์ใหม่ทับของเดิม แล้วแก้เลขเวอร์ชันในบรรทัดแรกของ `sw.js`
(`const CACHE = 'sky-wallet-v2-1'` → `v2-2`) แอปบนเครื่องทุกคนจะอัปเดตเองเมื่อเปิดครั้งถัดไป
