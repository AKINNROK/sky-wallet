# ☁️ Sky Wallet — เอาขึ้นคลาวด์แล้วติดตั้งลงหน้าจอ

> 🔄 **อยากให้มือถือกับคอมเห็นข้อมูลชุดเดียวกัน?** อ่าน **SUPABASE-SETUP-TH.md** ในโฟลเดอร์นี้

โฟลเดอร์นี้คือ **Progressive Web App (PWA)** พร้อมใช้งานจริง
อัปโหลดขึ้นเว็บฟรี → ได้ลิงก์ https → กดติดตั้งลงหน้าจอได้เหมือนแอปจากสโตร์

---

## ⭐ วิธีที่ 1 — Netlify Drop (เร็วสุด ~2 นาที ไม่ต้องสมัครก็ลองได้)

1. แตกไฟล์ zip ให้ได้โฟลเดอร์ `sky-wallet`
2. เปิด **https://app.netlify.com/drop**
3. **ลากโฟลเดอร์ `sky-wallet` ทั้งอัน** ไปวางบนหน้าเว็บ (ลากโฟลเดอร์ ไม่ใช่ไฟล์เดี่ยว)
4. รอ 10–30 วินาที จะได้ลิงก์ `https://ชื่อสุ่ม.netlify.app`
5. สมัครบัญชีฟรี (Login with Google/GitHub) เพื่อ **เก็บลิงก์ไว้ถาวร** + เปลี่ยนชื่อเป็น
   `https://sky-wallet-ของฉัน.netlify.app` ที่ Site settings → Change site name

## ⭐ วิธีที่ 2 — GitHub + Vercel (ฟรีถาวร อัปเดตง่าย)

1. สมัคร/เข้า **github.com** → **New repository** ตั้งชื่อ `sky-wallet` เลือก **Public** → Create
2. กด **Add file → Upload files** ลากไฟล์ทุกไฟล์ในโฟลเดอร์นี้เข้าไป → Commit
3. **บอกชื่อ repo กลับมาที่แชตนี้** (เช่น `ชื่อผู้ใช้/sky-wallet`)
   เดี๋ยวฉันเชื่อม Vercel ให้เอง แล้วส่งลิงก์ production กลับให้ค่ะ
   *(หรือทำเองก็ได้: vercel.com → Add New Project → Import repo → Deploy)*

## วิธีที่ 3 — GitHub Pages

Settings → Pages → Source: `main` / `root` → Save → ได้ `https://ชื่อผู้ใช้.github.io/sky-wallet/`

## 📲 ติดตั้งลงหน้าจอ (หลังมีลิงก์แล้ว)

| อุปกรณ์ | วิธีทำ |
|---|---|
| **Android (Chrome)** | เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** |
| **iPhone / iPad** | เปิดด้วย **Safari เท่านั้น** → ปุ่มแชร์ ↑ → **เพิ่มไปยังโฮมสกรีน** |
| **คอม (Chrome / Edge)** | เปิดลิงก์ → ไอคอน ⊕ ท้ายช่องที่อยู่เว็บ → ติดตั้ง |

ติดตั้งแล้วได้ไอคอนน้องเมฆบนหน้าจอ เปิดเต็มจอไม่มีแถบเบราว์เซอร์ และ **ใช้งานได้แม้ไม่มีเน็ต**

## 📁 ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `sw.js` | Service Worker — ทำให้ใช้ออฟไลน์ได้ และทำให้ปุ่ม "ติดตั้งแอป" โผล่ |
| `manifest.webmanifest` | ชื่อ ไอคอน สี เปิดเต็มจอ + ทางลัดเพิ่มรายรับ/รายจ่าย |
| `vercel.json` | ตั้งค่า header ให้ Vercel (ข้ามได้ถ้าใช้เจ้าอื่น) |
| `icon-*.png`, `apple-touch-icon.png`, `favicon.png` | ไอคอนน้องเมฆทุกขนาด |

## 🔐 ข้อมูลของคุณ

* เก็บอยู่ใน **เครื่องของคุณเอง** ไม่ส่งขึ้นเซิร์ฟเวอร์ใด ๆ แม้จะเปิดผ่านลิงก์
* แต่ละอุปกรณ์จึงมีข้อมูลของตัวเอง — ย้ายข้อมูลด้วย
  **เมนู → 💾 สำรองข้อมูล** ที่เครื่องเดิม แล้ว **🧰 เครื่องมือ → นำเข้าไฟล์** ที่เครื่องใหม่
* เช็กสถานะได้จากปุ่ม **☁️ / 💾** บนหัวแอปตลอดเวลา
* ⚠️ อย่ากด "ล้างข้อมูลเว็บไซต์" ในเบราว์เซอร์ และควรสำรองไฟล์ไว้เป็นระยะ

## 🔄 อัปเดตแอปในอนาคต

อัปโหลดไฟล์ใหม่ทับของเดิม แล้วแก้เลขเวอร์ชันบรรทัดแรกของ `sw.js`
(`sky-wallet-v2-1` → `v2-2`) เครื่องทุกเครื่องจะอัปเดตเองเมื่อเปิดครั้งถัดไป
